Which frequencies drive the decision?

occlusion test: remove one band, re-run the model, measure the change

For every window, each frequency band is deleted from the audio (FFT → zero the band → inverse FFT) and the model is run again: – extra inferences.

A long bar means that removing the band costs the model confidence in its answer, so the model relies on that band. A bar to the left means the band was pulling it towards another class.

Why this test

A factory is loud. The training set mixed room noise into pump clips at 5–20 dB signal-to-noise ratio so the classifier would keep working when people talk or a fan runs.

This test measures that claim directly: the same clips, with noise added at a fixed SNR, through the same model.
